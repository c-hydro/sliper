# SLIPER documentation

SLIPER (Soil Landslide Information and Prediction & Early Response) combines rainfall, soil moisture, and soil-slip observations to support landslide forecasting and early warning. The repository README covers installation and running a standalone application. [SLIPER repository](https://github.com/c-hydro/sliper)
